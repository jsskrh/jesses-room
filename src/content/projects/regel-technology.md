## What I did

I lead the engineering function at Regel Technology.

- **Developer APIs:** secure API infrastructure, including the generation and management of API keys and endpoints for developers integrating with the platform.
- **Messaging:** in-app notifications, REST APIs and the SMPP protocol.
- **Billing:** payment gateway integrations for automated billing and credit management.
- **Infrastructure:** AWS, with ECS for container orchestration, VPC for network security, and Redis for caching and message queuing.
- **New capabilities:** frontend implementation specifications and technical assessments for gift card purchasing and WhatsApp Business Platform integration.
